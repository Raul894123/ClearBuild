# Архитектура ClearBuild · SAQ QURYLYS

## Поток данных и обработка сигналов
1. **Сбор и OCR:** Публикации из Krisha.kz, Instagram, Telegram и скриншоты сторис поступают во входной буфер.
2. **ИИ-анализатор:** Модуль на основе регулярных выражений и NLP-эвристик распознаёт триггеры незаконного сбора денег (платная бронь, депозит, первоначальный взнос, касса, резерв) и расхождения готовности.
3. **Человек в контуре (Human-in-the-Loop):** ИИ формирует гипотезу с оценкой уверенности и выделением точного фрагмента текста. Балл в скоринг **не начисляется** до подтверждения аналитиком МИО.
4. **Детерминированный скоринг (R1-R6):** Суммируются веса подтверждённых факторов. Распределяются цветовые зоны (Зелёная, Жёлтая, Красная).
5. **Сигнальная карточка:** Генерация официальной карточки первичного реагирования с резолюцией и печатью PDF.
